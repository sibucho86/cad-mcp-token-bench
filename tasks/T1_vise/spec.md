## 仕様: マシンバイス（万力）

### 座標系と単位
- 単位は mm。Z が上向き。X はジョーが開く方向。
- 原点は、固定ジョーの面（X=0）、ベース底面（Z=0）、幅方向の中央（Y=0）。
- 「ねじ軸」とは、Y=0・Z=35 を通る X 方向の直線のこと。
- 以下の座標はすべて初期姿勢（組み立てた状態）でのグローバル座標。

### 部品一覧（6種類・計8個）

#### 1. Base（1個）
1つのソリッド。次の3つの直方体を合体する。
- 台: X −40〜160, Y −40〜40, Z 0〜20
- 固定ジョー: X −40〜0, Y −40〜40, Z 20〜60
- ねじ受けブロック: X 140〜160, Y −20〜20, Z 20〜50

そこから次を除去する。
- 案内溝: X 0〜140, Y −15〜15, Z 12〜20 の直方体
- ねじ穴: ねじ軸と同軸の φ16.5 の穴。ねじ受けブロックを X 方向に貫通（X 140〜160）
- 取付穴: φ11 の穴を4個。台を Z 方向に貫通。中心は (X, Y) = (20, 30), (20, −30), (120, 30), (120, −30)

仕上げ: 外形の四隅の鉛直エッジ（平面視で (−40, ±40) と (160, ±40) の角）に R5 のフィレット。

#### 2. MovableJaw（1個）
- 本体: X 50〜90, Y −40〜40, Z 20〜60 の直方体
- 案内キー: X 50〜90, Y −14.5〜14.5, Z 12.5〜20 の直方体（本体と一体）
- ねじ受け穴: ねじ軸と同軸の φ12.5 の止まり穴。背面（X=90）から深さ 20（X 70〜90）、穴底は平ら

#### 3. JawPlate（2個。同じ部品を2回配置する）
部品単体の形（部品座標 x, y, z）:
- 板: x 0〜10, y −40〜40, z 0〜20。x=0 が取付面、x=10 が締付面
- ざぐり穴を2個: 中心 (y, z) = (25, 10) と (−25, 10)。x 方向に φ6.6 で貫通し、締付面側から φ11・深さ 6.5 のざぐり
- 締付面（x=10 の面）の外周4辺に C1 の面取り

初期姿勢:
- JawPlate 1個目: 固定ジョーの面に取り付ける。X 0〜10, Y −40〜40, Z 40〜60。締付面は +X 向き
- JawPlate 2個目: 可動ジョーの面に取り付ける。X 40〜50, Y −40〜40, Z 40〜60。締付面は −X 向き（1個目を Z 軸まわりに 180° 回した向き）

#### 4. Screw（1個。ねじ山は省略する）
ねじ軸と同軸の段付き丸棒。
- 軸端: φ12, X 71〜90
- 軸: φ16, X 90〜210
- 頭部: φ26, X 210〜226。頭部の両端面の外周エッジに C1 の面取り
- 横穴: φ8.5 で、頭部を Y 方向に貫通。穴の中心軸は X=218, Z=35 を通る Y 方向の直線

#### 5. Handle（1個）
- φ8・長さ 160 の丸棒。軸は Y 方向で X=218, Z=35 を通る。初期姿勢で Y −80〜80

#### 6. HandleKnob（2個。同じ部品を2回配置する）
部品単体の形:
- φ16・長さ 14 の円柱
- 一方の端面の中心に、φ8・深さ 8 の止まり穴（穴底は平ら）
- 穴のない側の端面の外周エッジに R2 のフィレット

初期姿勢（どちらも軸は X=218, Z=35 を通る Y 方向）:
- HandleKnob 1個目: Y 72〜86。穴の口は Y=72 側で、Handle の +Y 端が穴に 8 入る
- HandleKnob 2個目: Y −86〜−72。穴の口は Y=−72 側（1個目と逆向き）

### ジョイント（アセンブリの拘束）
- Base を接地（固定）する。
- J1: JawPlate 1個目 – Base … 固定（剛体）
- J2: MovableJaw – Base … スライダー。X 方向の直進だけを許す
- J3: JawPlate 2個目 – MovableJaw … 固定（剛体）
- J4: Screw – MovableJaw … 回転。ねじ軸まわりの回転だけを許す
- J5: Handle – Screw … 円筒。横穴の軸（Y 方向）に沿った直進と、その軸まわりの回転を許す
- J6: HandleKnob 1個目 – Handle … 固定（剛体）
- J7: HandleKnob 2個目 – Handle … 固定（剛体）
- ジョイントを付けた後も、すべての部品が上の初期姿勢の位置にあること。

### 名前
部品（コンポーネント）の名前は、Base, MovableJaw, JawPlate, Screw, Handle, HandleKnob とする。2個ある部品は、同じ部品の2つのインスタンスとして配置する。
