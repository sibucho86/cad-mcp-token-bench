## 仕様: 4軸ロボットアーム（2本指グリッパー付き）

### 座標系と単位
- 単位は mm。Z が上向き。
- 原点は、Base の底面の中心。
- 「旋回軸」とは、原点を通る Z 方向の直線（X=0, Y=0）のこと。
- 肩・肘・手首の軸は、どれも Y 方向の直線。初期姿勢では、次の点を通る。
  - 肩の軸: (0, 0, 80)
  - 肘の軸: (106.066, 0, 186.066)。正確には (75√2, 0, 80 + 75√2)
  - 手首の軸: (190.919, 0, 101.213)。正確には (135√2, 0, 80 + 15√2)
- 初期姿勢は、肩と肘を曲げ、手が真下を向く姿勢。腕は XZ 平面に沿って、+X の側へ伸びる。
  - UpperArm は、肩の軸から、水平より 45° 上の向き (0.70711, 0, 0.70711) に伸びる。
  - Forearm は、肘の軸から、水平より 45° 下の向き (0.70711, 0, −0.70711) に伸びる。UpperArm と Forearm の間の角度は 90°。
  - GripperBody と Finger は傾けない。指の先は真下（−Z）を向く。
- 以下の座標は、とくに断らない限り、初期姿勢（組み立てた状態）でのグローバル座標。
- 座標の小数は、小数第3位までに丸めた値。方向の 0.70711 は、√2/2（cos 45°）を丸めた値。
- 「部品座標 x, y, z」で形を示した部品は、「配置」に、部品座標の原点を置く位置と、部品座標の x, y, z 軸がグローバル座標で向く方向を示す。

### 部品一覧（6種類・計7個）

#### 1. Base（1個）
- 円板: φ140、厚さ 20。旋回軸と同軸で、Z 0〜20

そこから次を除去する。
- 中央の穴: 旋回軸と同軸の φ30.5 の穴。Z 方向に貫通
- 取付穴: φ9 の穴を6個。Z 方向に貫通。中心は、旋回軸を中心とする半径 60 の円の上に、+X 方向から 60° おきに並ぶ。中心の (X, Y) は (60, 0), (30, 51.962), (−30, 51.962), (−60, 0), (−30, −51.962), (30, −51.962)

仕上げ: 上面（Z=20）の外周エッジに C2 の面取り。

#### 2. Turret（1個）
1つのソリッド。次を合体する。
- 円板: φ100、厚さ 15。旋回軸と同軸で、Z 20〜35。下面は Base の上面に接する
- ボス（下に出た円柱）: φ30。旋回軸と同軸で、Z 8〜20。Base の中央の穴に入る
- 耳を2枚: どちらも XZ 平面に平行な、厚さ 10 の板。+Y 側の耳は Y 5〜15、−Y 側の耳は Y −15〜−5
  - 耳の形（XZ 平面での輪郭）: X −20〜20, Z 35〜80 の長方形の上に、中心 (X, Z) = (0, 80)・半径 20 の半円をのせた形。上端が半円になる。下端は円板の上面につながる

そこから次を除去する。
- 軸穴: 肩の軸と同軸の φ12 の穴。2枚の耳を Y 方向に貫通（Y −15〜15）

#### 3. UpperArm（1個）
部品単体の形（部品座標 x, y, z）:
- 板: 厚さ 10（y −5〜5）。xz 平面での輪郭は、x 0〜150, z −15〜15 の長方形の両端に、中心 (x, z) = (0, 0) と (150, 0)・半径 15 の半円を付けた形（両端が半円）
- 穴を2個: φ12。中心 (x, z) = (0, 0)（肩側の穴）と (150, 0)（肘側の穴）。y 方向に貫通
- 肉抜きの長穴: x 45〜105, z −6〜6 の長方形の両端に、中心 (x, z) = (45, 0) と (105, 0)・半径 6 の半円を付けた形。y 方向に貫通

配置（初期姿勢）:
- 部品座標の原点（肩側の穴の中心で、板の厚さの中央）を (0, 0, 80) に置く
- 回転: 肩の軸のまわりに 45° 回す。+X の側が上がる向きで、方向 (0, −1, 0) に対して右ねじの向き（方向 (0, 1, 0) に対する右ねじの角度で書くと −45°）
- 部品座標の軸が向く方向: x → (0.70711, 0, 0.70711), y → (0, 1, 0), z → (−0.70711, 0, 0.70711)
- 肘側の穴の中心は (106.066, 0, 186.066)
- 板は Y −5〜5 にあり、Turret の2枚の耳の間に入る。板の両面は、耳の内側の面（Y=−5 と Y=5）に接する

#### 4. Forearm（1個）
部品単体の形（部品座標 x, y, z）:
- 板: 厚さ 8（y −4〜4）。xz 平面での輪郭は、x 0〜120, z −12〜12 の長方形の両端に、中心 (x, z) = (0, 0) と (120, 0)・半径 12 の半円を付けた形（両端が半円）
- 穴を2個: φ12。中心 (x, z) = (0, 0)（肘側の穴）と (120, 0)（手首側の穴）。y 方向に貫通

配置（初期姿勢）:
- 部品座標の原点（肘側の穴の中心で、板の厚さの中央）を (106.066, 9, 186.066) に置く
- 回転: 肘の軸のまわりに 45° 回す。+X の側が下がる向きで、方向 (0, 1, 0) に対して右ねじの向き。回す前の部品座標の向きからの回転で、UpperArm に対する角度ではない
- 部品座標の軸が向く方向: x → (0.70711, 0, −0.70711), y → (0, 1, 0), z → (0.70711, 0, 0.70711)
- 手首側の穴の中心は (190.919, 9, 101.213)
- 板は Y 5〜13 にある。−Y 側の面（Y=5）は、肘では UpperArm の +Y 側の面に、手首では GripperBody の取付板の +Y 側の面に接する

#### 5. GripperBody（1個）
部品単体の形（部品座標 x, y, z。原点は、手首の穴の中心で、取付板の厚さの中央）:

1つのソリッド。次を合体する。
- 取付板: 厚さ 10（y −5〜5）。xz 平面での輪郭は、x −12〜12, z −25〜0 の長方形の上に、中心 (x, z) = (0, 0)・半径 12 の半円をのせた形
- 掌（てのひら）のブロック: x −40〜40, y −15〜15, z −45〜−25 の直方体。上面で取付板とつながる

そこから次を除去する。
- 手首の穴: φ12。中心 (x, z) = (0, 0)。y 方向に貫通
- 指の案内溝: x −40〜40, y −5〜5, z −45〜−37 の直方体。掌の下面にある幅 10・深さ 8 の溝で、x 方向に貫通する

仕上げ: 掌のブロックの、z 方向の4本の角のエッジ（(x, y) = (40, 15), (40, −15), (−40, 15), (−40, −15) の角）に R5 のフィレット。

配置（初期姿勢）:
- 回転しない（部品座標の x, y, z 軸は、グローバルの X, Y, Z 軸と同じ向き）。手は真下を向く
- 部品座標の原点を (190.919, 0, 101.213) に置く
- グローバル座標では、取付板は Y −5〜5、掌は X 150.919〜230.919, Y −15〜15, Z 56.213〜76.213、案内溝の天井は Z=64.213
- 取付板の +Y 側の面（Y=5）は、Forearm の −Y 側の面に接する

#### 6. Finger（2個。同じ部品を2回配置する）
部品単体の形（部品座標 x, y, z）:
- 角棒: x 0〜10, y −5〜5, z −50〜0 の直方体。z=0 の面が根元（溝に入る端）、z=−50 の面が先端。x=0 の面が、つかむ側の面
- 先端の面取り: 先端の、つかむ側のエッジ（x=0, z=−50 の、y 方向のエッジ）だけに C4 の面取り

配置（初期姿勢。同じ部品の別の配置）:
- Finger 1個目: 回転しない（部品座標の x, y, z 軸は、グローバルの X, Y, Z 軸と同じ向き）。部品座標の原点を (205.919, 0, 64.213) に置く。X 205.919〜215.919, Y −5〜5, Z 14.213〜64.213。つかむ側の面（X=205.919）は −X を向く
- Finger 2個目: 1個目を Z 軸まわりに 180° 回した向き。部品座標の軸が向く方向: x → (−1, 0, 0), y → (0, −1, 0), z → (0, 0, 1)。部品座標の原点を (175.919, 0, 64.213) に置く。X 165.919〜175.919, Y −5〜5, Z 14.213〜64.213。つかむ側の面（X=175.919）は +X を向く。上から見ると、GripperBody の中心（X=190.919, Y=0）について、1個目と点対称
- 2本の指の、つかむ側の面の間は 30
- どちらも、根元から 8（Z 56.213〜64.213）が GripperBody の案内溝に入る。根元の面（Z=64.213）は溝の天井に、Y=−5 と Y=5 の面は溝の側面に接する

### ジョイント（アセンブリの拘束）
- 軸の点と方向は、初期姿勢でのグローバル座標で示す。回転の正の向きは、方向ベクトルの向きに右ねじが進む向きとする。スライダーの正の向きは、方向ベクトルの向きとする。正の向きは記録のためのもので、CAD のジョイントの正の向きは、これと逆でもよい。
- 軸ピンは省略する。J2〜J4 は、同じ軸の上にある φ12 の穴どうしをつなぐ。
- Base を接地（固定）する。
- J1: Turret – Base … 回転。旋回軸（点 (0, 0, 20) を通り、方向 (0, 0, 1) の直線）まわりの回転だけを許す。正の向きは、上から見て反時計回り
- J2: UpperArm – Turret … 回転。肩の軸（点 (0, 0, 80) を通り、方向 (0, −1, 0) の直線）まわりの回転だけを許す。正の向きは、腕が上がる向き
- J3: Forearm – UpperArm … 回転。肘の軸（点 (106.066, 0, 186.066) を通り、方向 (0, −1, 0) の直線）まわりの回転だけを許す。正の向きは、前腕の先が上がる向き
- J4: GripperBody – Forearm … 回転。手首の軸（点 (190.919, 0, 101.213) を通り、方向 (0, −1, 0) の直線）まわりの回転だけを許す。正の向きは、指の先が +X の側へ振れる向き
- J5: Finger 1個目 – GripperBody … スライダー。案内溝に沿った、方向 (1, 0, 0) の直進だけを許す（指の開閉）。正の向きは、開く向き
- J6: Finger 2個目 – GripperBody … スライダー。案内溝に沿った、方向 (−1, 0, 0) の直進だけを許す。正の向きは、開く向き。J5 とは独立に動く（2本の指を連動させない）
- 接地のほかのジョイントは、J1〜J6 の6個（回転4、スライダー2）だけにする。全体の自由度は 6。
- ジョイントを付けた後も、すべての部品が上の初期姿勢の位置にあること。

### 名前
部品（コンポーネント）の名前は、Base, Turret, UpperArm, Forearm, GripperBody, Finger とする。2個ある部品（Finger）は、同じ部品の2つのインスタンスとして配置する。
