## 仕様: 軸受ユニット（ピローブロック＋Vプーリー）

### 座標系と単位
- 単位は mm。Z が上向き。X はシャフト（軸）の方向。
- 原点は、BasePlate の底面（Z=0）の中央。BasePlate は X −130〜130, Y −45〜45 にある。
- 「シャフト軸」とは、Y=0・Z=50 を通る X 方向の直線のこと。
- 以下の座標はすべて初期姿勢（組み立てた状態）でのグローバル座標。
- 2個ある部品は、部品単体の形を部品座標 (x, y, z) で1回だけ示し、そのあとで2つの配置を示す。どちらの配置も回転はなく、部品座標の x, y, z はグローバルの X, Y, Z と同じ向き。

### 部品一覧（6種類・計8個）

#### 1. BasePlate（1個）
- 板: X −130〜130, Y −45〜45, Z 0〜12 の直方体（260×90×12）
- 取付穴: φ11 の穴を4個。板を Z 方向に貫通。中心は (X, Y) = (−100, 37), (−100, −37), (100, 37), (100, −37)

仕上げ: 外形の四隅の鉛直エッジ（平面視で (±130, ±45) の角）に R8 のフィレット。

#### 2. PillowBlock（2個。同じ部品を2回配置する）
部品単体の形（部品座標 x, y, z。z=0 が底面）:
- 本体: 次の外形の図形（yz 平面に平行な面に描く）を、x −12〜12 に押し出す（厚さ 24）。
  - 外形: (y, z) = (−45, 0) → (45, 0) → (45, 12) → (29, 12) → (29, 38) → 円弧 → (−29, 38) → (−29, 12) → (−45, 12) → (−45, 0)
  - 円弧は、中心 (0, 38)・半径 29 の半円で、上の点 (0, 67) を通る。両端で胴の側面になめらかにつながる
  - できる形: 取付脚（幅 90・高さ 12）の上に、幅 58 の胴が立つ。胴の上は半円。全高 67
- 軸受の座: φ47 の穴。中心軸は y=0, z=38 を通る x 方向の直線。本体を x 方向に貫通
- 取付穴: φ11 の穴を2個。取付脚を z 方向に貫通。中心 (x, y) = (0, 37), (0, −37)

初期姿勢:
- PillowBlock 1個目: 部品座標の原点を (X, Y, Z) = (−100, 0, 12) に置く。X −112〜−88, Y −45〜45, Z 12〜79
- PillowBlock 2個目: 部品座標の原点を (100, 0, 12) に置く。X 88〜112, Y −45〜45, Z 12〜79
- どちらも、底面は BasePlate の上面に接し、取付穴は BasePlate の取付穴と同軸。座の中心軸はシャフト軸に重なる

#### 3. Bearing（2個。同じ部品を2回配置する。玉は省略する）
部品単体の形（部品座標 x, y, z）:
- 外径 47・内径 20・幅 14 のリング（1つのソリッド）。中心軸は x 軸で、x −7〜7
- 外周と内周の、両端面側の円形エッジ（計4本）に C0.5 の面取り

初期姿勢（どちらも中心軸はシャフト軸）:
- Bearing 1個目: 部品座標の原点を (−100, 0, 50) に置く。X −107〜−93（PillowBlock 1個目の座の中で、厚さの中央）
- Bearing 2個目: 部品座標の原点を (100, 0, 50) に置く。X 93〜107（PillowBlock 2個目の座の中で、厚さの中央）
- 外周面は座の穴の面に接し、内周面は Shaft の外周面に接する（どちらも直径が同じで、すきまはない）

#### 4. Shaft（1個）
- φ20 の丸棒。シャフト軸と同軸で、X −120〜180（長さ 300）
- 両端面の外周エッジに C1 の面取り
- キー溝: X 137〜173, Y −3〜3, Z 56.5〜60 の範囲の材料を除去する（幅 6・長さ 36。軸の上端 Z=60 からの深さ 3.5）。溝の底は Z=56.5 の平面、両端は X=137 と X=173 の平面（両端に丸みはない）

#### 5. VPulley（1個）
シャフト軸を中心とする回転体で、X 135〜175 にある。
- 断面: 次の点を順に直線で結んだ多角形を、シャフト軸まわりに 360° 回す。点は (X, r) で示す。r はシャフト軸からの距離（例えば Y=0 の平面に描くなら、点 (X, r) はグローバルの (X, 0, 50 + r)）
  - (135, 10) → (175, 10) → (175, 22) → (161, 22) → (161, 44) → (175, 44) → (175, 62.5) → (169, 62.5) → (165, 50.5) → (160, 50.5) → (156, 62.5) → (154, 62.5) → (150, 50.5) → (145, 50.5) → (141, 62.5) → (135, 62.5) → (135, 44) → (149, 44) → (149, 22) → (135, 22) → 最初の点 (135, 10) に戻る
  - できる形: 軸穴 φ20、ボス（外径 44・幅 40）、ウェブ（厚さ 12、X 149〜161）、リム（内径 88・外径 125・幅 40）。リムの外周に V 溝が2本（溝の中心は X=147.5 と X=162.5。溝の上の幅 13、深さ 12、底の幅 5）
- 肉抜き穴: φ14 の穴を4個。ウェブを X 方向に貫通。中心は、シャフト軸から 33 の円の上に 90° おき: (Y, Z) = (0, 83), (33, 50), (0, 17), (−33, 50)
- 軸穴のキー溝: X 135〜175, Y −3〜3, Z 50〜62.8 の直方体を除去する（幅 6 で X 方向に貫通。溝の底は Z=62.8 の平面）
- 軸穴は Shaft の外周面に接する（直径が同じで、すきまはない）
- VPulley は BasePlate の端（X=130）より外（+X 側）にあり、すきまは 5。外径が大きいので、下端（Z=−12.5）は BasePlate の下面（Z=0）より下に出る。これは仕様どおりで、どの部品とも干渉しない

#### 6. Key（1個）
- X 137〜173, Y −3〜3, Z 56.5〜62.5 の直方体（幅 6・高さ 6・長さ 36）
- Shaft のキー溝にちょうど入る（底面・両側面・両端面が溝の面に接する）。上面と VPulley のキー溝の底（Z=62.8）の間には 0.3 のすきまがある

### ジョイント（アセンブリの拘束）
- 軸の点と方向は、初期姿勢でのグローバル座標で示す。回転の正の向きは、方向ベクトルの向きに右ねじが進む向きとする。正の向きは記録のためのもので、CAD のジョイントの正の向きは、これと逆でもよい。
- BasePlate だけを接地（固定）する（ほかの部品は接地しない）。
- J1: PillowBlock 1個目 – BasePlate … 固定（剛体）
- J2: PillowBlock 2個目 – BasePlate … 固定（剛体）
- J3: Bearing 1個目 – PillowBlock 1個目 … 固定（剛体）
- J4: Bearing 2個目 – PillowBlock 2個目 … 固定（剛体）
- J5: Shaft – Bearing 1個目 … 回転。シャフト軸（点 (−100, 0, 50) を通り、方向 (1, 0, 0) の直線）まわりの回転だけを許す。正の向きは、+X 側から見て反時計回り（初期姿勢で真上にある Key は −Y 側へ動く）
- J6: VPulley – Shaft … 固定（剛体）
- J7: Key – Shaft … 固定（剛体）
- Shaft と Bearing 2個目の間には、ジョイントを付けない。同じ軸に回転ジョイントを2つ付けると、拘束が重複するため。Shaft は Bearing 2個目の内径に接したまま、その中で回る（Bearing 2個目は動かない）。
- 接地のほかのジョイントは、上の7つ（固定6、回転1）だけにする（例えば Key – VPulley の間にも付けない）。全体の自由度は1（Shaft・VPulley・Key が一緒に、シャフト軸まわりに回る）。
- ジョイントを付けた後も、すべての部品が上の初期姿勢の位置にあること。

### 名前
部品（コンポーネント）の名前は、BasePlate, PillowBlock, Bearing, Shaft, VPulley, Key とする。2個ある部品（PillowBlock と Bearing）は、それぞれ同じ部品の2つのインスタンス（同じ部品の別の配置）として配置する。同じ形を2回作らない。
