## 仕様: スライダークランク（単気筒エンジンの模型）

### 座標系と単位
- 単位は mm。Z が上向き。
- 原点は、クランク軸線とシリンダー軸線の交点。
- 「クランク軸線」とは、原点を通る Y 方向の直線（X=0, Z=0）のこと。Crankshaft は、この直線のまわりに回る。
- 「シリンダー軸線」とは、原点を通る Z 方向の直線（X=0, Y=0）のこと。Piston は、この直線に沿って動く。
- −Y の側が正面（手前）。手前から順に、コンロッド（ConRod。Y −4〜4）、フライホイール（Y 5〜15）、背板（Y 25〜35）が並ぶ。
- 以下の座標は、「部品座標」と断ったものを除き、すべて初期姿勢（組み立てた状態）でのグローバル座標。
- 初期姿勢では、クランクピンがクランク軸線の真横（+X 側。シリンダー軸線と直角の向き）にある。クランクピンの中心軸は (X, Z) = (28, 0) を、ピストンピン（WristPin）の中心軸は (X, Z) = (0, 96) を通る（28² + 96² = 100²）。

### 部品一覧（5種類・計5個）

#### 1. Frame（フレーム。1個）
1つのソリッド。次の3つの直方体を合体する。
- 台: X −60〜60, Y −40〜35, Z −60〜−50
- 背板: X −40〜40, Y 25〜35, Z −50〜150
- シリンダーブロック: X −25〜25, Y −25〜25, Z 60〜150。後ろの面（Y=25）で背板に付く

そこから次を除去する。
- シリンダー穴: シリンダー軸線と同軸の φ40.4 の穴。シリンダーブロックを Z 方向に貫通（Z 60〜150）
- クランク軸の穴: クランク軸線と同軸の φ12.5 の穴。背板を Y 方向に貫通（Y 25〜35）

#### 2. Crankshaft（クランク軸。1個）
1つのソリッド。次の3つの円柱を合体する。
- フライホイール: クランク軸線と同軸の φ80 の円板。Y 5〜15
- 軸: クランク軸線と同軸の φ12 の円柱。Y 15〜40。背板の穴を通り、背板の後ろの面（Y=35）から 5 出る
- クランクピン: φ10 の円柱。中心軸は (X, Z) = (28, 0) を通る Y 方向の直線。Y −8〜5。フライホイールの前の面（Y=5）から手前に出て、コンロッドの大端の穴を通る

#### 3. ConRod（コンロッド。1個。傾けて配置する）
部品単体の形（部品座標 x, y, z。y が厚さの方向）:
- 大端のボス: φ24 の円柱。中心軸は (x, z) = (0, 0) を通る y 方向の直線。y −4〜4
- 小端のボス: φ18 の円柱。中心軸は (x, z) = (0, 100) を通る y 方向の直線。y −4〜4
- 棒: x −5〜5, y −4〜4, z 0〜100 の直方体（2つのボスをつなぐ）
- 以上を合体し、y 方向に貫通する穴を2つあける。穴の中心間は 100。
  - 大端の穴: φ10.5。中心軸は (x, z) = (0, 0)
  - 小端の穴: φ8.5。中心軸は (x, z) = (0, 100)

初期姿勢:
- 大端の穴の中心軸は (X, Z) = (28, 0) を通る（クランクピンの中心軸と同じ）。小端の穴の中心軸は (X, Z) = (0, 96) を通る（ピストンピンの中心軸と同じ）。厚さの範囲は Y −4〜4。
- これは、部品座標の形を、y 軸（大端の穴の中心軸）まわりに −16.2602°（= −asin(28/100)。+y の向きに右ねじが進む向きを正とする）回し、大端の穴の中心を (28, 0, 0) へ平行移動した姿勢。部品座標の y は、グローバルの Y と同じ向き。
- 部品座標の軸が向く方向: x → (0.96, 0, 0.28), y → (0, 1, 0), z → (−0.28, 0, 0.96)。部品座標の原点（大端の穴の中心）は (28, 0, 0) に置く。
- このとき、大端から小端へ向かう中心線（部品座標の +z の向き）は (−0.28, 0, 0.96) を向き、+Z から −X の側へ 16.26° 傾く。

#### 4. Piston（ピストン。1個）
- 本体: シリンダー軸線と同軸の φ40 の円柱。Z 76〜116（頂面が Z=116、底面が Z=76）
- 溝（コンロッドの小端が入る）: Y −4.5〜4.5（幅 9）の部分を、X 方向に貫通して、底面（Z=76）から Z=107 まで除去する。Z 107〜116 は残す
- ピストンピンの穴: φ8 の穴。中心軸は (X, Z) = (0, 96) を通る Y 方向の直線。Y 方向に貫通

#### 5. WristPin（ピストンピン。1個）
- φ8・長さ 36 の丸棒。中心軸は (X, Z) = (0, 96) を通る Y 方向の直線。Y −18〜18
- ピストンの穴（φ8）と、コンロッドの小端の穴（φ8.5）を通る

### ジョイント（アセンブリの拘束）
- 軸の点と方向は、初期姿勢でのグローバル座標で示す。回転の正の向きは、方向ベクトルの向きに右ねじが進む向きとする。スライダーの正の向きは、方向ベクトルの向きとする。正の向きは記録のためのもので、CAD のジョイントの正の向きは、これと逆でもよい（例えば J1 の軸の向きが (0, −1, 0)、J5 の向きが (0, 0, −1) でもよい）。
- Frame だけを接地（固定）する（ほかの部品は接地しない）。
- J1: Crankshaft – Frame … 回転。クランク軸線まわりの回転だけを許す。軸は点 (0, 0, 0) を通り、方向 (0, 1, 0)。正の向きは、正面（−Y 側）から見て時計回り（クランクピンが +X 側から −Z 側へ動く向き）
- J2: ConRod – Crankshaft … 回転。クランクピンの中心軸まわりの回転だけを許す。軸は点 (28, 0, 0) を通り、方向 (0, 1, 0)。正の向きは、正面（−Y 側）から見て時計回り（Crankshaft に対して、コンロッドの小端が +X 側へ振れる向き）
- J3: WristPin – Piston … 固定（剛体）
- J4: ConRod – WristPin … 回転。ピストンピンの中心軸まわりの回転だけを許す。軸は点 (0, 0, 96) を通り、方向 (0, 1, 0)。正の向きは、正面（−Y 側）から見て時計回り（WristPin に対して、コンロッドの大端が −X 側へ振れる向き）
- J5: Piston – Frame … スライダー。シリンダー軸線に沿った直進（方向 (0, 0, 1)）だけを許す。正の向きは +Z（ピストンが上がる向き）
- 接地のほかのジョイントは、J1〜J5 の5個（固定1、回転3、スライダー1）だけにする。種類を変えたり、ジョイントを足したり外したりしない。
- J5 で、Frame → Crankshaft → ConRod → WristPin → Piston → Frame のループが閉じる。組み上がった機構の自由度は 1。Crankshaft を回すと、コンロッドを介して、Piston がシリンダー軸線に沿って上下に動く。
- ジョイントを付けた後も、すべての部品が上の初期姿勢の位置にあること。

### 名前
部品（コンポーネント）の名前は、Frame, Crankshaft, ConRod, Piston, WristPin とする。どの部品も1個ずつ配置する。
